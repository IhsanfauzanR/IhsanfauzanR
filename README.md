I'm Deezai. I build web software, and I sell some of it.

Most of what I make goes out under **[Talvenward](https://talvenward.com)**, a one-person
studio selling website templates as source code. One at a time, each one finished before the next
one starts. The repositories are private, because the source is the product.

### How I build

Every template is drawn rather than decorated. The geometry on the page is generated from the
content files, so changing the content changes the drawing, and nothing has to be kept in step by
hand.

Before one is listed I drive it in real Chrome across every route, every viewport it claims to
support, and both motion modes. Then I extract the sale archive into an empty directory somewhere
else entirely and take it through install, build and test, the way a buyer would. That last step
has caught a script `package.json` advertised but the download did not contain, and a browser gate
that only knew the demonstration's own routes.

The gate gets broken on purpose before it is trusted. Every assertion has to report a defect
planted for it, or it is decoration rather than a check. One of them was decoration for a while,
and the day it was written properly it found text a phone had been hiding.

I would rather find the defect than have a buyer find it.
